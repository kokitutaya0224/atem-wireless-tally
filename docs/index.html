ATEM Tally

Wireless Tally Light Installer

このブラウザはWeb Serialに対応していません。
Google Chrome または Microsoft Edge をお使いください。

ESP8266をUSBケーブルでPCに接続し、
書き込みたいファームウェアの Install ボタンをクリックします。

WiFi タリーWiFi
従来版。タリー自身がWiFiでATEMに接続します。
LoRa ベース局（送信機）LoRa
WiFiでATEMに接続し、全カメラのタリーをE220-900T22S(JP)で920MHz帯ブロードキャスト。1台だけ用意します。
LoRa タリー受信機LoRa
LoRaで受信してLED表示。WiFi環境不要。カメラごとに1台。

※ このブラウザがWeb Serial非対応（Safari等）の場合、Installボタンは表示されません。 Chrome または Edge をお使いください。

Setup Steps — WiFi タリー
  1. 上のボタンでファームウェアをESP8266に書き込み
  2. 書き込み完了後、ESP8266が再起動し ATEM-Tally WiFiが出現
  3. スマホまたはPCで ATEM-Tally に接続
  4. ブラウザで http://192.168.4.1 にアクセス
  5. WiFiネットワーク、ATEM IPアドレス、カメラ番号を設定
  6. 「Save & Restart」で保存 → タリーライトが動作開始
Setup Steps — LoRa タリー
  1. 1台目に「LoRa ベース局」、2台目に「LoRa タリー受信機」を書き込み
  2. 両方のESP8266にE220-900T22S(JP)を配線（下記Wiring参照）し、アンテナを必ず装着
  3. ベース局: AP ATEM-Tally-BASE に接続 → http://192.168.4.1 でWiFiとATEM IPを設定
  4. 受信機: AP ATEM-Tally-RX に接続 → http://192.168.4.1 でカメラ番号を選択
  5. ベース局のLEDが緑点灯（ATEM接続）になれば受信機にタリーが飛びます

無線設定（CH10 / 922.6MHz / SF7 / 13dBm）はファームウェアが起動時に自動で書き込むため、E220側の事前設定は不要です。 詳細は docs/lora-tally.md を参照。

Wiring — WiFi タリー
RGB LED (Common Anode) ├── R (Red) → D5 (GPIO14) + 220Ω ├── Long leg → 3.3V ├── G (Green) → D6 (GPIO12) + 220Ω └── B (Blue) → D7 (GPIO13) + 220Ω Reset Button (Optional) └── D1 (GPIO5) → GND
Wiring — LoRa 版（ベース局・受信機 共通）
E220-900T22S(JP)-EV2 ├── VCC → 3V3 ※5V(VIN)は厳禁 ├── GND → GND ├── M0 → D3 (GPIO0) ├── M1 → D4 (GPIO2) ├── RXD → D1 (GPIO5) ※クロス接続 ├── TXD → D2 (GPIO4) ※クロス接続 ├── AUX → 未接続 └── ANT → TX915-JK-11 ※必ず装着してから電源ON RGB LED (Common Anode) ※受信機は必須 ├── R (Red) → D5 (GPIO14) + 220Ω ├── Long leg → 3.3V ├── G (Green) → D6 (GPIO12) + 220Ω └── B (Blue) → D7 (GPIO13) + 220Ω Reset Button (Optional) └── D0 (GPIO16) → 3.3V ※WiFi版(GND)と異なり3.3Vへ

E220のUART信号レベルは電源電圧に追従します。5Vで給電するとESP8266が破損するため、必ず3.3Vに接続してください。

設定をリセットするには、以下のいずれかの方法を使用してください：

ボタン: リセットボタンを押しながら電源ON（WiFi版: D1→GND ／ LoRa版: D0→3.3V）
ブラウザ: http://<IP>/reset にアクセス
シリアル: 115200bpsで reset と送信（LoRa受信機は cam5 のようにカメラ番号変更も可能）
